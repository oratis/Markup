# 星号之下 —— 语言史话

> 1868 年，奥古斯特·施莱歇尔用一门已经死了六千年、从来没有人记录过、也从来没有人听过的语言，写了一则关于绵羊和马的寓言。
>
> 每一个词的前面，他都加了一个星号。
>
> 星号的意思是：**我知道它存在过，虽然没有人见过它。**

一部语言的史话。**人物传记与学科进展混写**，整体风格参照曹天元《上帝掷骰子吗？——量子物理史话》，与同仓库的《要有光——人工智能史话》同一体例。

## 这本书跟别的语言史有什么不一样

市面上讲语言的书大致三类：讲语言学概念的（教材）、讲某一门语言的（英语史、汉语史）、讲"世界上有多少种奇怪语言"的（趣味读物）。

这本书是第四类：**它讲一群人怎么把"人怎么说话"这件事，从猜想变成可以查证的知识。**

三条硬性主张，贯穿全书：

1. **语言不留化石，所以这门学科的主角是方法。** 全书的中心符号是那个星号——一个重构形式前面的记号，意思是"没有人记录过它，但它必须存在过"。星号兑现过（第 13 章，五十年后在赫梯语里找到了那个音），也落空过（第 14 章，"雅利安人"是从一个语言学术语长成一场灾难的）。
2. **每一个语系背后都是一次人的移动。** 语言学是唯一一门能看见没有文字的人群的学科。第四卷的十一章不是"世界语言名录"，是十一次迁徙。
3. **不评价语言的高下。** "原始""简单""没有语法"这类说法，在本书里一律当作待订正的流言处理（[写作规范](提纲/写作规范.md) §四）。

## 怎么写

### 协作方式

**一次一章。** 这条是硬规矩，不是建议——史话的密度是整章级的，分次续写接缝会很明显。

每章流程固定四步：

1. **对纲** —— 读该卷的[细纲](第一卷-开口/_卷细纲.md)，确认本章的场景、人物、要讲透的点。
2. **核实** —— 把本章要用的年份/数字/引文过一遍来源，填进[参考资料](提纲/参考资料.md)；拿不准的原地标 `[[待核实]]`，绝不含糊过去。
3. **写** —— 一次写完整章（6 500–8 500 字）。
4. **收尾** —— 更新 frontmatter 的 `status` / 字数 → [人物谱](提纲/人物谱.md) → [时间线](提纲/时间线.md) → **给[语系谱](提纲/语系谱.md)销账** → 本 README 看板。

### 硬规矩

- **不编造史实。** 允许场景化的笔法，但凡具体的时间、地点、人物言行必须有出处；无法确证的一律写成"据说 / 传说 / 有一种说法"，或者直接不写。
- **引文短且注出处。** 不整段搬运他人文字。
- **术语第一次出现给中英对照**，此后统一用中文。译名对照见[人物谱](提纲/人物谱.md)。
- **每门语言第一次出现给语系 + 分布 + 人数量级。** 第四卷会出现三百多个语言名，读者需要钩子。
- **重构形式一律带星号，且在 Markdown 里转义成 `\*`。**
- **每章结尾留"本章欠账"区块**（`<!-- 欠账: … -->`），成书前统一清理。
