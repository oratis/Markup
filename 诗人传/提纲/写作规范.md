# 写作规范

参照对象有两个。**工程体例**照搬姊妹书《要有光》《星号之下》；**笔法**不照搬——那两本是史话，这本是小说。小说的参照是传记小说这一路：写一个人的一生，让读者跟着他走，而不是听叙述者讲他。

**写每一章之前重读一遍这份文件。** 尤其是 §四：哪一层可以编，哪一层绝不可以。

---

## 一、结构

1. **一章一人，从生写到死，再写到身后。** 不截取"最精彩的一段"——这本书的主张是诗要放回一生里看，截了一段就失去了这个主张。死和身后事是硬性要求：谁收了他的诗、谁替他定了名、哪一首传开了哪一首丢了。
2. **章内分六到九节**，用 `## 一` `## 二` 编号，节下可以有短小标题也可以没有。每节对应一生的一个阶段，大体顺时间走；允许一章里有一处倒叙或前置（比如第 6 章以 756 年的菩提寺开场再回到 717 年），**但全书二十二章不要都用同一个花样**。
3. **开场必须是一个具体场景**：一个人在某一天做一件具体的事。不要"王维，字摩诘，太原祁人"式的列传开头，也不要"盛唐是中国诗歌的黄金时代"式的背景开头。**也不要每章都用"年份，地点。"这种裸句开场**——姊妹书的去模板轮查出二十八处，这是 AI 味最重的一种模板。开场的花样要换：可以从一件器物、一句话、一个动作、一封信进入。
4. **每章结尾一张"本章诗作编年"表**，放在正文之后、欠账之前，格式见 §三。它是这一章的年谱，也是工具抽数据的地方。
5. **章与章之间要有穿线**，尤其是同一卷内：王维章里李白同年生却无一诗相及，李白章里要让读者想起这件事；杜甫替王维写过辩护诗，两章各写一次，从两边看。**穿线靠内容，不靠"详见第 X 章"**——小说里不许出现章号互指。

---

## 二、腔调

6. **第三人称，贴着主角的限知视角走。** 叙述者知道主角此刻知道的事，不预告他的未来。"他不知道，三年后这首诗会救他的命"——这种句子一章最多一次，用在最值的地方。
7. **讲诗的时候叙述者可以现身**，像说书人停下来说一段。但要克制：讲完就回到故事里，不做总结，不说"我们来看"。**"我们"这个词全章不超过三次**——那是史话的声音，不是小说的。
8. **幽默要有，但比姊妹书淡。** 低调陈述仍然是主心骨：大事用轻的词，数字越吓人句子越短。一本正经讲荒谬也可以用（玄宗朝的官制、科举的规矩，本来就荒谬）。**但下面这些段落整段禁用幽默**：任何人的死、国破、丧妻丧子、俘虏营、贬谪路上的病、装哑的那三个月。
9. **不要行话，不要文学史术语。** "山水田园诗派""盛唐气象""沉郁顿挫""豪放派"——这些词一个都不要出现在叙事里。读者不需要知道王维属于哪一派，只需要知道他那天在辋川看见了什么。
10. **文言引文之外，叙事用现代汉语，但不用现代词。** "心理阴影""情绪价值""内卷"这类词一出现，唐朝就没了。同样也不要故意仿古，"乃""遂""焉"不要往叙述里塞。**试金石：这句话念给一个今天的人听不别扭，念给一个唐朝人听也不荒唐。**
11. **句子长短混着来。** 场景和动作用短句；一个人的一生在某一节要被迅速带过时，可以放长句。每章至少有一处留白——一行字，或者一个单句成段。

## 三、诗的嵌入

12. **处境先于诗。** 每一首诗出现之前，读者必须已经知道：他在哪里，几岁，官居何职或者已经不做官，刚刚发生了什么。**诗是那一刻的结果，不是插图。** 先把人带到那一天，再让诗出来。

13. **引用格式固定**（工具靠它抽编年表，不要变体）：

    ```markdown
    > 《九月九日忆山东兄弟》　开元五年（717）· 十七岁 · 长安
    >
    > 独在异乡为异客，每逢佳节倍思亲。
    > 遥知兄弟登高处，遍插茱萸少一人。
    ```

    第一行：书名号题目 + 全角空格 + 年号纪年（公元）+ 岁数 + 地点，用 `·` 分隔。**系年不详的如实写**：`《相思》　系年不详（约天宝年间）· 长安？`。岁数按虚岁，与年谱体例一致；本书各章统一用虚岁，编年表里注明。

14. **短诗引全，长诗节引。** 绝句、律诗、小令一律全引；《长恨歌》《离骚》《正气歌》这种节引，节引处用 `……` 标明。**节引不是挑金句**——要挑能承接这一刻处境的那一段。

15. **讲诗的三条规矩**：
    - **落在字上。** 讲"返景入深林"就讲"返景"是什么时候的光、为什么是"复照"；不讲"营造了幽静的意境"。
    - **用到这一刻。** 讲解必须引用刚才叙事里交代过的处境，否则这首诗为什么要放在这里？"松风吹解带"——解的是官带，他刚从给事中的位置上告假回辋川。
    - **有长度上限。** 绝句的讲解不超过 300 字，律诗与小令不超过 500 字，长诗节引不超过 700 字。讲不完的是不该讲的。

16. **禁语表**。下面这些词在讲诗的段落里一个都不要出现：表达了、抒发了、体现了、反映了、寄托了、诗人通过、全诗、意境、情景交融、脍炙人口、千古名句、传诵千古、脍炙、不朽、家喻户晓、耐人寻味、言有尽而意无穷。`style_audit.py` 会数。

17. **一章里不同的诗要用不同的讲法。** 有的诗讲一个字，有的讲它跟上一首的差别，有的干脆不讲——让处境自己讲。**一章里如果每首诗后面都跟着一段分析，读起来就是教辅。** 比例上，一章至少有三分之一的诗是"不讲"或"只点一句"的。

18. **编年表格式**：

    ```markdown
    ## 本章诗作编年

    | 年 | 岁 | 诗 | 地点 | 处境 | 系年依据 / 争议 |
    |---|---|---|---|---|---|
    | 717 | 17 | 九月九日忆山东兄弟 | 长安 | 离家两年，初到京城 | 题注"时年十七" |
    | — | — | 相思 | 长安？ | — | 无系年依据；李龟年江南所唱为传说 |
    ```

    **系年依据一栏不能空。** 依据可以是题注、诗中自述、本事、官职对应、年谱家的推断——但要写明是哪一种，有争议的写"一作 ×× 年，从陈铁民"。

## 四、史实纪律：三层虚构边界

这是小说，不是史话，所以姊妹书那条"不编造言行"在这里要改写。改写成三层，**每一层的尺度不同，逐层标明**。

19. **骨架层——绝不虚构。** 生卒年、籍贯、家世、科举年份、历任官职与品级、迁徙路线与年份、亲属的生死、重大历史事件、**每一首诗的系年与本事**。这一层的每一条都必须有出处（正史本传、墓志、年谱、集校注），有争议的取一说并在编年表和欠账里登记。**改了这一层的任何一条，这本书就不再是"把诗放回那一天"，而是把诗放到一个编出来的日子里。**

20. **血肉层——可以虚构，但必须合时代。** 天气、光线、屋舍、器物、饮食、路程、衣着、动作、身边的人在做什么。这一层是小说之所以是小说的地方，放开写。但有一条：**物质细节必须是那个时代的。** 几个常踩的坑：
    - 唐人席地或坐胡床，不坐椅子（椅子普及在宋）；
    - 唐人煎茶不泡茶，宋人点茶，明以后才泡；
    - 唐代没有"状元"这个固定说法，有"状头"；
    - 唐代官员的"假"是按旬休，"告假"有定制；
    - 宋以前的灯是油灯，蜡烛是贵物；
    - 唐人叫"郎君""娘子"，不叫"公子""小姐"；"先生"在唐指老师或道士。
    拿不准就不写那个细节——**少一个细节没人发现，错一个细节全章失信。**

21. **声音层——有限虚构。** 对话与内心活动。允许写他想什么、怕什么、记起什么；允许写短对话。三条约束：
    - **史料有记载的言行，按记载写**，不改不增。王维临终"索笔作别缙书"，那就是索笔写信，不要让他临终说一段话。
    - **不让人物说出后世的评语。** 王维不知道自己"诗中有画"，杜甫不知道"诗圣"，李清照不知道"婉约"。这些话只能出现在"身后"一节，由后人说。
    - **不编造"名言"。** 对话宁短勿长，宁平勿警。一个人物说出一句漂亮话的时候，问一句：这句话有出处吗？没有就删。
    - 内心活动不超过叙事的四分之一。小说写的是一个人做了什么、看见了什么，不是他心里的独白。

**四之二、传说的处理。** 岐王带王维去见玉真公主、黄狮子、李白捞月、杜甫吃牛肉而死、孟浩然"不才明主弃"惹恼玄宗、李煜七夕牵机药、陆游与唐琬在沈园相遇——这些故事流传极广，多出自唐宋笔记，**可信度各不相同，但都不能当骨架用**。处理办法：
    - **不用"订正"区块**。姊妹书的去模板轮把三十处订正区块全部化进了叙事，教训是：一本书里反复出现同一种"辟谣"格式，读者读到第三次就知道下面要说什么了。
    - 传说可以进叙事，但放在**流传**的位置上：用"后来的人说""《集异记》里有一个故事""三十年后有人这样写"这类口吻把它引出来，**让读者看出它是谁在什么时候说的**。
    - 主角本人不经历传说。王维不会"记得"自己弹琵琶给公主听，因为那件事是否发生过无人知道；但叙述者可以在讲他身后事的时候说，这个故事是怎么流传起来的。

**四之三、在世的争议与系年争议。** 许多名篇的系年在年谱家之间有争议（《夜雨寄北》是写给妻子还是友人、《声声慢》在南渡前还是后、《钗头凤》是否真有其事）。**正文取一说，不裁决，争议写进编年表**。选哪一说的标准：有题注从题注，有本事从本事，两说相持从近人年谱（见[参考资料](参考资料.md)）。

## 五、人物

22. **主角第一次出现给名和字，此后叙事里只用名。** 不用号（"东坡""稼轩""易安"），不用官称（"王右丞""杜工部"）——那些都是别人对他的称呼，放进"身后"一节。同时代人称呼他可以用字或官称，那是对话。
23. **配角第一次出现给生卒年（已知的话）和一句速写。** 速写抓具体特征：不是"著名宰相张九龄"，是"张九龄，岭南人，开元朝最后一个敢在玄宗面前反对李林甫的宰相"。生卒年放在括号里，一次，之后不再出现。
24. **每个主角的亲人要有名字和下落。** 妻子、兄弟、儿女——正史本传往往一笔带过，年谱里能找到的都要用。王维的弟弟王缙、裴迪；杜甫的妻子杨氏、幼子饿死；李清照的丈夫赵明诚；陆游的儿子。**一个人的一生里，这些人的生死是比官职更重的时间戳。**
25. **全部人物登记在[人物谱](人物谱.md)**，写完一章必须回填。

## 六、篇幅与工程

26. **一章 8 000–11 000 字**（序章、终章 3 500–5 000），一次写完。低于下限要检查是不是漏了纲——一生不可能在七千字里写完整；高于上限要检查是不是在复述诗的内容。
27. **frontmatter 是元数据的唯一来源**：

    ```yaml
    ---
    status: draft          # outline | draft | revise | done
    target_words: 10000
    words: 0               # 定稿后回填实际字数
    synopsis: 一句话概要，会显示在卡片墙上
    poet: 王维
    span: 701–761
    people: [王缙, 裴迪, 张九龄, 崔希逸, 孟浩然]
    poems: [九月九日忆山东兄弟, 使至塞上, 鹿柴]   # 本章嵌入时间线的诗，用于对诗目销账
    ---
    ```

28. **章末留欠账区块**，用 HTML 注释，成书前统一清理：

    ```markdown
    <!-- 欠账:
    - [ ] 王维生年 701 / 699 两说，从 701，待对陈铁民《王维年谱》
    - [ ] 黄狮子一事的笔记出处 [[待核实]]
    -->
    ```

29. **写完一章的收尾动作**（五件，别漏）：更新本章 frontmatter → 回填[人物谱](人物谱.md) → 回填[时间线](时间线.md) → **给[诗目](诗目.md)销账** → 更新 [README](../README.md) 看板。

30. **字数口径**与姊妹书一致：去 frontmatter、去 HTML 注释、去 Markdown 强调与代码记号、去空白，数字符。实现在 `tools/measure.py`。**注意引用的诗也算正文**——一章一万字里诗本身大约占八百到一千五，这是设计内的。

## 七、自查清单

每章交稿前逐条过：

- [ ] 开头是一个具体场景，不是列传开头或背景开头；不是"年份，地点。"裸句
- [ ] 从生写到死，写到了身后事（谁收诗、谁定名、什么传说是什么时候起来的）
- [ ] 六到九节
- [ ] 每首诗出现前，读者已经知道他在哪里、几岁、什么处境
- [ ] 诗的引用格式统一；短诗全引；节引处有 `……`
- [ ] 讲诗落在字上、用到处境、不超长度；禁语表清零；至少三分之一的诗"不讲"
- [ ] 骨架层每一条都有出处或已登记争议；血肉层没有穿越的器物；声音层没有后世评语、没有编造的名言
- [ ] 传说都放在"流传"的位置上，主角本人不经历传说
- [ ] 主角只用名；配角有生卒和速写；亲人有名字和下落
- [ ] 叙事里没有文学史术语，没有现代词，没有章号互指
- [ ] "我们"≤3；死亡、国破、俘虏段落没有幽默
- [ ] 编年表完整，系年依据一栏无空白
- [ ] `[[待核实]]` 已清零或转入欠账
- [ ] 至少碰到两条[母题](全书提纲.md#三贯穿全书的六条母题)
- [ ] frontmatter、人物谱、时间线、诗目、README 看板都已更新
