# 参考资料

**骨架层（§四·19）的每一条都要能追到这里。** 分两档：全书通用的，和分章的。系年相持时从哪家年谱，在这里定，正文不再解释。

---

## 一、全书通用

| 类 | 书 | 用法 |
|---|---|---|
| 正史本传 | 《史记》《三国志》《宋书》《旧唐书》《新唐书》《宋史》《金史》《清史稿》各本传 | 骨架层的第一依据；两《唐书》不一致时注明 |
| 总集 | 《全唐诗》《全宋词》《全金元词》 | 诗的文本以各家校注本为准，总集只作备查 |
| 年谱通论 | 来新夏《近三百年人物年谱知见录》；谢巍《中国历代人物年谱考录》 | 查某一位诗人有哪些年谱、谁的最可信 |
| 职官 | 《旧唐书·职官志》《唐六典》；龚延明《宋代官制辞典》 | 官职品级、任期规制、休假制度 |
| 历史地理 | 谭其骧《中国历史地图集》；严耕望《唐代交通图考》 | 贬谪路线、里程、驿程日数 |
| 物质生活 | 孙机《中国古代物质文化》；扬之水《唐宋家具寻微》 | 血肉层的时代细节：坐具、灯烛、茶、衣冠 |
| 笔记 | 《集异记》《本事诗》《明皇杂录》《唐语林》《世说新语》《默记》《齐东野语》 | **只作传说来源**，不作骨架依据；引用时正文须点明出处时代 |

## 二、分章

### 二之〇、各章系年的默认依据

**这张表是「骨架层每一条都要能追到这里」的兑现方式**：一首诗到底系在哪一年，先看这一章从哪一家；
与那一家不同的，正文与章末编年表里逐条注明。**表由各章编年表的说明行汇成，改了那一行就来改这里。**

**这一栏里那些近人年谱、校注本，多数不在网上**——两轮清账为它们留下了大量「纸本不可及」。
第二轮又用搜韵 API 与四部丛刊本翻掉了一批；哪些还站着、走到哪一步了，看各章欠账区块与
[出处入口](出处入口.md)，不要重走。
