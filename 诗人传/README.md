# 当时明月 —— 中国诗人列传

> 中国人背诗，背的是诗，不是人。一首《静夜思》在所有人嘴里都一样；可在李白嘴里，它只属于某一个夜晚。
>
> 一首诗在被写下之前，是一个人的处境；在被写下之后，才变成所有人的句子。
>
> 这本书要做的，是把诗放回它被写下的那一天。

一部中国诗人的传记小说集。**一章写一个诗人的一生**，用叙事小说的笔法从生写到死，而他那些人人会背的诗，按写成的年份一首一首地嵌回他当时的处境里——读者读到《使至塞上》时，已经跟着王维走到了凉州城外，知道他为什么会在那里。

与同仓库的《要有光——人工智能史话》《星号之下——语言史话》同一工程体例（frontmatter、看板、欠账、工具链），**但体裁不同**：那两本是史话，这一本是小说。两者的边界写在[写作规范](提纲/写作规范.md) §四——哪一层可以虚构、哪一层绝不可以。

## 这本书跟别的诗人传有什么不一样

市面上讲诗人的书大致三类：诗选加注释的（教辅）、一人一本的学术传记（年谱体）、以及"诗词里的那些事"式的趣味读物（段子体）。

这本书是第四类：**它把年谱写成小说。**

三条硬性主张，贯穿全书：

1. **诗是处境的时间戳。** 全书的方法是"系年"——这首诗到底写在哪一年、哪里、写的人当时几岁、官居何职、刚刚发生了什么。一首诗的意思，一半在字里，另一半在那一天。《凝碧池》四句，不知道王维那时装哑巴装了三个月，读到的只是秋槐落叶。
2. **虚构的是感受，不虚构的是事实。** 小说可以写他看见什么、想起什么、怎样沉默；不可以改他的生年、官职、贬谪的年份，不可以替他说出后人替他总结的话。边界在[写作规范](提纲/写作规范.md) §四，三层，逐层标明。
3. **不写成功者列传。** 这二十二个人里，死在任上的是少数。被贬、被俘、被杀、国破、丧妻、丧子、装哑、投江——这些不是点缀，是这些诗的成本。每一章都要写到死，写到身后事。

## 怎么写

### 协作方式

**一次一章。** 一章是一个人的一生，八千到一万一千字，必须一气写完——分次续写的接缝在小说里比在史话里更明显，因为人物的声音会变。

每章流程固定五步：

1. **对纲** —— 读该卷的[细纲](第二卷-长安/_卷细纲.md)，确认本章的分节、每节落哪几首诗。
2. **排年谱** —— 把本章要用的诗逐首系年，填进[诗目](提纲/诗目.md)；系年有争议的，正文取一说，争议写进章末编年表的备注。
3. **核骨架** —— 生卒、官职、迁徙、科考、亲属、事件，逐条对[时间线](提纲/时间线.md)与[参考资料](提纲/参考资料.md)；拿不准的原地标 `[[待核实]]`。
4. **写** —— 一次写完整章。
5. **收尾** —— 更新 frontmatter → 回填[人物谱](提纲/人物谱.md) → 回填[时间线](提纲/时间线.md) → **给[诗目](提纲/诗目.md)销账** → 本 README 看板。

### 硬规矩

- **骨架层不虚构。** 生年、官职、年份、诗的本事，必须有出处；有争议的取一说并登记。
- **不让诗人说出后人的评语。** 王维不知道自己"诗中有画"，杜甫不知道自己是"诗圣"。
- **诗一律原文引全**（长篇节引），用固定的引用格式（见[写作规范](提纲/写作规范.md) §三），工具靠它抽编年表。
- **讲诗不用教辅腔。** "表达了诗人……的思想感情"这类句子一句都不要；讲诗要落在具体的字上，并且必须用到这一刻的处境。
- **每章结尾一张"本章诗作编年"表**，成书时它就是这一章的年谱。
- **每章结尾留"本章欠账"区块**（`<!-- 欠账: … -->`），成书前统一清理。

### 这也是一次 dogfooding

本书与两本姊妹书一样，是 Markup [写作模式](../docs/design/07-writing-mode.md)的真实项目：

- [`_manuscript.md`](_manuscript.md) 是稿件树索引（嵌套列表 + wikilink）。
- 每章 frontmatter 的 `status` / `target_words` / `synopsis` / `poet` / `poems` 是卡片墙和进度视图的数据源。
- 比姊妹书多两个字段：`poet`（本章主角）与 `poems`（本章嵌入的诗）——后者用来对[诗目](提纲/诗目.md)自动销账。
