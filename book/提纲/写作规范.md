# 写作规范

参照对象：**曹天元《上帝掷骰子吗？——量子物理史话》**（2003 年起网络连载，后出版）。

那本书公认的几个特征：用讲故事的方式重现学科的"发家历程"，被形容为**"演义式"甚至"武侠小说"般的笔法**，人物刻画鲜明、语言诙谐生动；作者自述**大部分时间精力用在构思故事，少部分用在科普知识本身**，目标是"科学文化熏陶"而非教材替代。

下面是把这种风格落成可执行规则。**写每一章之前重读一遍这份文件。**

---

## 一、结构

1. **开头不要背景介绍。** 禁止"XX 世纪中叶，随着技术的发展……"这类开场。**具体场景是最常用的一种办法，不是唯一的办法**——也可以从一句话、一个数字、一张图、一个反常的结果、一份文件的原文进来。

    > **2026-08 订正。** 这一条原来写的是"每章正文开头**必须**是一个具体场景：时间、地点、一个人在做一件具体的事"。结果是 33 篇里 25 篇以年份开场，其余几篇也是同一个运镜换了主语（"一个模型正在读一个德语句子""一道数学奥赛题摆在屏幕上"）。**连着三十多章用同一种镜头语言，"场景化"就退化成了格式。** 下限生产整齐，整齐读起来像机器。改成禁令，形状交回给材料。

2. **节数由材料定。** 2 到 7 节都可以，每节 1 200–3 500 字，节与节之间可以跳时间、跳地点。**全书的节数分布不应该整齐。**

    > **2026-08 订正。** 原文是"章内用一、二、三、四分节"，实际执行成 33 篇里 32 篇正好五节。一个允许区间会被当成目标值取上限——这是这份规范反复出过的事故。人物章可以用一条生命线一贯到底，争论章可以双方并排，产业章可以按资金、组织、产品三条线走，不必都切成五段。

3. **一章一个主角，或者一对对手。** 群像留给时代细纲，正文里读者一次只需要记住一到两个名字。第 10 章是罗森布拉特对明斯基，第 19 章是辛顿一门三代，第 22 章是八个人——那一章的处理方式在细纲里另有说明。
4. **结尾不要总结段。** 一章讲完就停。钩子是**可以**用的一种收法——用悬念，不用"下一章我们将介绍……"这种目录腔：*"而此时，在康奈尔的一间实验室里，一个心理学家正在给一台机器接线。"* 但**不是每章都欠读者一个钩子**：有些章的最后一句就该是它自己的最后一句，落在一个事实、一句原话或一个没有答案的问题上。
5. **每个时代的第一章开头**要有一段"此刻另一条线"，交代同时期另一条技术路线在干什么（分期交叠的代价，见[全书提纲](全书提纲.md) §二）。

## 二、腔调

6. **可以对读者说话，但要省着用。** *"别急，先记住这个名字，二十年后他会回来。"* 这是史话的招牌动作，**每章至多三两次**，否则油。注意这是上限，不是配额：一整章一次都不用，完全可以。
7. **允许调侃、允许吐槽、允许打比方打得夸张**——但**只对事、不对人下判决**。可以说"这个预言后来被现实抽得很响"，不要说"某某是个蠢货"。
8. **比喻必须自己站得住。** 一个好比喻胜过三段解释；一个歪比喻会让读者一路错到底。每写下一个比喻，反问一句"这个比喻在哪里会失效"，如果失效点很关键，就在正文里点出来。
9. **不要行话开场。** 术语第一次出现给中英对照并当场用一句话解释，此后统一用中文。**读者被劝退是在第一次遇到不解释的术语的那一刻。**
10. **句子长短混着来。** 解释技术时用短句；写场景和人物时可以放长。整章读起来要有呼吸。

## 二之二、英式幽默

**英式幽默不是段子，不是网络梗，也不是在严肃段落后面补一句俏皮话。** 它是几种具体的句法动作，可以照着做。以下七条与上面的"腔调"并行生效。

25. **低调陈述（understatement）——这套幽默的主心骨。** 事情越大，用词越轻；数字越吓人，句子越短。
    - ✗ "这是一场灾难性的失败，整个领域为之震动。"
    - ✓ "这个方案有一个小问题：它不工作。"
    - 用法：重大的翻车、惊人的数量级，一律用一个平静的短句去接。**让落差自己产生效果。**

26. **一本正经讲荒谬（deadpan）。** 荒唐的事用公文或教科书的语气叙述，不加感叹号，不提醒读者这里好笑。
    - 例：斯金纳的鸽子导弹，要用海军立项报告的口吻写。

27. **自嘲，不嘲人。** 靶子的优先级：**制度 > 时代风气 > 叙述者自己 > 某个具体观点**。人排最后，而且只能嘲他的**判断**，不能嘲他的**处境**。
    - 允许："我在这一章要讲的，说白了是一台机器把一种掷骰子的棋下得很好。请再忍我一节。"
    - **禁止**：拿死亡、疾病、迫害、精神崩溃、贫穷开任何玩笑。**图灵、罗森布拉特、皮茨、鲁梅尔哈特、魏泽鲍姆**这五个人的相关段落整段禁用幽默——这是规则 20 的对偶条款。

28. **括号里的旁白。** 正文正着说，括号里斜着补一句。最省力也最容易过量的一招——**每节最多两处**。
    - 例："（这条规则后来进了教科书。教科书没有交代它是怎么来的。）"

29. **反高潮（bathos）。** 排比堆到第三项时突然落地。
    - 例："他们需要三样东西：一套理论、一台机器，以及一个肯付钱的人。前两样有了。"

30. **把礼貌话翻译成人话。** 学术界和官僚机构的客气措辞照原样引一句，然后给出直译。
    - 例："委员会的原话是'该方向尚未展现出与投入相称的前景'。也就是：钱没了。"

31. **不解释笑点。** 写完不许补"是不是很讽刺""这就很有意思了"。**补了就废了。** 这一条是前六条的守门员。

**密度**：**只有上限，没有下限**——全章不超过十二处，每节不超过三处，括号旁白每节不超过两处。**幽默是调味不是主菜**——这本书首先要靠得住，其次才好笑。凡是幽默与准确起冲突的地方，**一律牺牲幽默**。

> **2026-08 订正。** 这一条原来写的是"每节至少一处"。一个下限意味着大约每 1 700 字必须响一次，不管那段材料想不想响。**结果是笑点像按配额出现，叙述者的机灵长期保持同一个温度，人物和时代反而被统一成了一种声腔。** 现在取消下限：**让材料决定这一节该不该有人笑。** 数学章可以更冷更精确，悲剧人物章可以一处都没有，产业史章可以让数字和组织细节自己说话。规则 27 那五个人的禁令不变。

## 三、科学内容

11. **每章的科学解释不超过全章 1/4 篇幅。** 超了就说明这章在写教程。
12. **解释一个概念的标准三件套**：
    - 一个**比喻**（让人有直觉）
    - 一个**最小具体例子**（能自己在纸上推一遍，比如 XOR 只有四行真值表、注意力就三个矩阵）
    - 一句**它解决了什么此前解决不了的问题**（否则读者不知道为什么该在意）
13. **公式最多一章一个，且必须逐项翻译成中文。** 能用一句话说清就不要用公式。全书的公式预算大约在第 5、13、22、24 章。
14. **数字必须准确**：日期、错误率、参数量、论文年份、奖项年份。写作时手边就是[时间线](时间线.md)，写完回填。

## 四、史实纪律

这是史话，不是历史小说。以下三条是硬约束：

15. **场景可以还原，细节不可以编造。** 允许"1958 年 7 月的华盛顿，记者们围住了一台机器"这种基于报道的场景重建；**不允许**给历史人物编造对话、心理活动、天气。凡是具体言行，必须有出处；只有二手来源的，明写"据某某回忆"。
16. **存疑就标记。** 拿不准的地方原地写 `[[待核实]]`，绝不用"据说""大约"含糊过去后就忘了。写完一章，占位符必须清零或转入[参考资料](参考资料.md)的待办。
17. **引文短且注出处。** 单次引用尽量控制在一两句之内，给出人名与出处；**不整段搬运他人文字**（这本书要能公开）。转述优先于引用。传说与神话（偃师、塔洛斯、魔像）注明是传说，且交代文献来源（如《列子·汤问》）。

**特别注意两类容易失手的地方**：

- **优先权之争**（反向传播被多次独立发现、LSTM 与施密德胡贝的争议）：给出各方的发表时间与文献，让读者自己判断。**不要写成八卦，也不要替谁站台。**
- **还在世的人**：写在世者的判断失误（明斯基对感知机的低估、各种落空的预言）时，写清楚**当时的信息条件**。事后诸葛亮是史话最廉价的一种写法。

## 五、人物

18. **每个人物第一次出现给两样东西**：生卒年（在世者只给生年）和一句人物速写。速写要抓住这个人的**具体特征**，不要用"杰出的科学家"。
19. **译名统一**，第一次出现时括注原名，此后只用中文。全部译名登记在[人物谱](人物谱.md)——**写完一章必须回填**，否则第 19 章会出现三种"苏茨克维"。
20. **让人物有失败。** 罗森布拉特的死、皮茨的凋零、图灵的结局、维纳与麦卡洛克的决裂、魏泽鲍姆对自己造物的恐惧——这些不是点缀，是这门学科真实的成本。**不要把史话写成成功者列传。**

## 六、篇幅与工程

21. **一章 8 000–12 000 字，一次写完。** 不要分次续写：史话的节奏感是整章级的，接缝会很明显。

    **字数口径（2026-08-01 订正）**：去 frontmatter、去 HTML 注释、**去 Markdown 的强调与代码记号**（星号、反引号、删除线），再去所有空白，然后数字符。
    此前的脚本把加粗记号也数成了正文——在粗体占比高的章里会虚增几百字，全书合计近一万字。**记号不是正文。**
    统一口径写在 `book/tools/measure.py`，所有脚本都从那里取。
22. **frontmatter 是元数据的唯一来源**：

    ```yaml
    ---
    status: outline        # outline | draft | revise | done
    target_words: 9000
    words: 0               # 定稿后回填实际字数
    synopsis: 一句话概要，会显示在卡片墙上
    people: [罗森布拉特, 明斯基]
    ---
    ```

23. **章末留欠账区块**，用 HTML 注释，成书前统一清理：

    ```markdown
    <!-- 欠账:
    - [ ] 1958-07-08 NYT 那篇报道的原标题需核对
    - [ ] 罗森布拉特与明斯基是否真是布朗克斯科学高中同学 [[待核实]]
    -->
    ```

**23 之二**. **辟谣用独立区块，且不编号。** 遇到流传广而站不住的说法，不要把订正揉进叙事，也**不要给它编号**。用一个独立区块处理：

    ```markdown
    > **订正 · 事由**
    >
    > **流传的说法**：……
    >
    > **可查的是**：……
    ```

    标题一律用事由，不用序号。**全书不做任何自指计数**——不写"这是本书第八次校正"、"母题六第三次出场"、"这句话被顶过五次"这类句子。理由有二：编号让各处彼此耦合，增删一处就要回去改别处；而正文里的自指计数读起来像在记账，把读者的注意力从事实本身挪到了作者的账本上。**要让读者感到"又是它"，靠的是内容的呼应，不是编号。**

24. **写完一章的收尾动作**（四件，别漏）：更新本章 frontmatter → 回填[人物谱](人物谱.md) → 回填[时间线](时间线.md) → 更新 [README](../README.md) 看板。

## 六之二、不留工序痕迹

这一节是 2026-08 全书通审后加的。审读意见把问题说得很准：**这本书最像机器写的地方，不是知识错误，而是过度稳定、过度清楚、过度会收束。**

而稳定是这份规范自己造的。上面每一条"下限"——开头必须是场景、每节至少一处幽默、至少碰到两条母题、每章一个钩子——都被忠实执行了三十三遍，于是三十三章长成了同一个形状。**痕迹不是写崩了，是守规矩守出来的。** 所以先改规范，再改正文；只改正文，下一章写出来还是老样子。

以下六条是硬约束。

32. **正文里不出现这本书的生产过程。** 读者要知道的是事实和论证，不是作者的工序。
    - **删**："这一节是全书两个技术高峰之一，请给它一点耐心"、"这一章要写得枯燥，因为规则本来就是枯燥的"、"我试过把它写得不枯燥，没有成功"、"按这个时代的落笔纪律，我在这一章不裁决"。
    - **办法**：把纪律**做出来**，不要**说出来**。不裁决，就并排摆好两边最强的论证然后停笔——读者看得出来你没选边，不需要你报告一次。同理：嫌某段枯燥就把它写短，不要预告它枯燥。

33. **不做任何自指计数。**（原 23 之二，提上来并扩大范围。）不写"这是本书第八次校正"、"母题六第三次出场"，**也不写"这本书讲了二十九章"、"写到第三十章"、"前面二十九章反复出现过"**。
    - 后面这一类是 2026-08 才发现的漏网形态：光第 29 章里"这本书讲了二十九章"就出现了六次。
    - **办法**：要让读者感到"又是它"，靠内容的呼应，不靠报数。"这个形状出现过很多次了"就够了，不必说是第几次。

34. **母题编号是编辑工具，不是读者可见的东西。** 正文一律不出现"母题一""母题五"字样（2026-08 审前全书正文有 48 处）。
    - **办法**：母题靠**同一种材料压力在不同年代重现**来生效，不靠点名。终章收三条最强的线就好，**不要逐条清点七条**——那读起来像项目验收，会把余味清干净。

35. **跨章导航减到最少。** "请回到第 7 章""第 22 章会回来""这条线留到后面"——保留那些读者真的需要才能读懂的，其余全删。
    - **判据**：删掉之后事实关系还成立吗？成立就不要补回来。
    - 需要指路时优先用**内容**认路（"维纳那一代人做的控制论"），而不是**编号**认路（"第 7 章那一代人"）。章号只在真会被翻回去查的地方留。

36. **句法不要长期依赖同一组动作。** 下面这些单独看都是好写法，连着三十万字用就变成了可预测：
    - "不是 A，而是 B"（审前 202 处）——同一章最多留两三处，其余改成直接陈述。
    - "真正的问题/原因/意义是……"、"这件事的意义比它看起来大得多"。
    - 长解释后接一个平静短句制造反高潮；每节最后用一句可摘录的判断封口。
    - **破折号**（审前 1 406 处，4.7 处/千字）——**减半**。补充关系不必都写成戏剧性转折，该用逗号、冒号、分号或干脆断句的地方就用。
    - **十字以内的独立短段**（审前 300 处）——只留给真正的转场或结论，其余并回上一段。

37. **作者的判断要标出来，但只标一次。** 书里凡是跨时代的类比、自己的分层整理、自己的对照，都必须让读者看出那是**本书的判断**，不是史学界共识——这一条是这本书最值钱的地方之一，**不许为了流畅把它删掉**。
    - 但**形式要压到最短**。不要每次都写一遍"这是本书自己的对照，不是当年谁的说法，这本书里凡是隔了几十年的类比都请这样读"。
    - **办法**：体例在[凡例](../凡例.md)里一次说清，正文里只留一个短标记——`（本书的对照。）`、`（本书的分层。）`、`（本书的推断。）`。省下来的字给事实。

## 七、自查清单

每章交稿前逐条过：

- [ ] 开头不是背景介绍；**这一章的开头和相邻几章不是同一个运镜**
- [ ] 节数是这批材料需要的节数，不是凑出来的五节
- [ ] 科学解释 ≤ 全章 1/4，且每个概念都有比喻 + 最小例子 + "它解决了什么"
- [ ] **每个比喻都补出了它在哪里失效**
- [ ] 每个新人物有生卒年 + 一句速写；译名已回填人物谱
- [ ] **没有一次性人名卡片**：只为交代一项小改进而出现的人，移进注释或人物谱
- [ ] 所有日期与数字已对照时间线核过
- [ ] 引文都短、都有出处，没有整段搬运
- [ ] `[[待核实]]` 已清零或转入参考资料待办
- [ ] 辟谣都放在独立的「订正」区块里

**去工序痕迹**（§六之二，每条都要过）：

- [ ] 正文没有一句在讲这本书**怎么写的**（"这一节是全书两个技术高峰之一""我在这一章不裁决"）
- [ ] **没有任何自指计数**——包括"这本书讲了二十九章""写到第三十章""前面二十九章"
