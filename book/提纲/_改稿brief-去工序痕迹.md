## 一、这一轮要解决什么

一份外部审读意见判定这本书「像 AI 深度参与」。它给的证据不是知识错误——**恰恰相反，它明确表扬了本书的事实核查、证据分级和对在世者的克制，并说这些"应保留"。** 它指认的是另一件事：

> **过度稳定、过度清楚、过度会收束。**

我核了它的每一条结构指控，全部属实：

| 它说的 | 实测 |
|---|---|
| 章节结构过于规整 | 33 篇里 **32 篇正好五节** |
| 开头是同一个运镜 | **25 篇以年份开场**，其余几篇是同一运镜换主语 |
| 叙述者不断解释自己的写法 | 自指 **616 处** |
| 正文出现内部母题编号 | **75 处**，其中约 48 处在章正文里 |
| 句法依赖对照与转折 | 「不是 A 而是 B」**202 处**，破折号 **1 406 处**（4.7/千字） |
| 幽默像按配额出现 | 规范原文写着"每节至少一处" |

还有一条它没查到、但更要紧的：

**「这本书讲了二十九章」这类数章数的句子，光第 29 章里就有六次。** 第 30 章同类型的还有两处。这是作者早就明令禁止过的东西（「全书都不要计数」），上一轮只清掉了「第 N 次辟谣」那一种形态，这一种漏了。

### 根因：痕迹是守规矩守出来的

[写作规范](写作规范.md)原来有一批**下限**——开头必须是场景、每节至少一处幽默、至少碰到两条母题、每章一个钩子、三到五节。三十三章忠实执行，就长成了同一个形状。

**规范已经先改完了**（§一 1–4、§二 6、§二之二密度、新增 §六之二、§七自查清单）。下限改成了上限与禁令。你改正文时依据的是**改后的规范**。

## 二、你要做的六件事

按 §六之二 的 32–37 条执行。逐条说明：

### 1. 删掉正文里讲「这本书怎么写」的句子

典型（都是真实句子）：

- 「这一节是全书两个技术高峰之一，请给它一点耐心。」
- 「这一章要写得枯燥，因为规则本来就是枯燥的。」「我试过把它写得不枯燥，没有成功。」
- 「按这个时代的落笔纪律，我在这一章不裁决。」
- 「不裁决是一条纪律，不是一种美德。真要有本事裁，我早裁了。」

**办法是把纪律做出来，不要说出来。** 不裁决就并排摆好两边最强的论证然后停笔——读者看得出来，不需要被告知。嫌一段枯燥就把它写短。

⚠️ **第五时代（26–31 章）的 agent 特别注意**：自指在这几章飙到全书最高（第 29、30、31 章分别是 34、40、40 处，是前期章节的三倍）。原因就是这个——**这个时代的落笔纪律在正文里反复自我报告**。删的是报告，**不是纪律本身**。不预测、不选边、对在世者克制、动机一律写「各方说法」——这些全部保留，只是不再挂在嘴上。

### 2. 删掉所有数章数的句子

「这本书讲了二十九章」「写到第三十章」「前面二十九章反复出现过」——**一处不留**。

要表达「又是它」，靠内容：「这个形状出现过很多次了」就够了，不必说是第几次。

### 3. 正文里不出现「母题一/二/三……」

母题靠同一种材料压力在不同年代重现来生效，不靠点名。

**终章的 agent 注意**：终章 4 733 字里有 10 处母题记账，是全书密度最高的。审读意见说得对——**逐条清点七条母题读起来像项目验收，会把余味清干净**。改成只收三条最强的线：

1. 规则与学习如何反复竞争、最终混合；
2. 一个想法何时从「想得到」变成「算得动」；
3. 洛夫莱斯—图灵—生成模型的创造问题。

「光与熵」留作文学隐喻，**不要写成关于智能本质的科学结论**。结尾要更短，最好停在问题还开着的地方。

### 4. 跨章导航减到最少

「请回到第 7 章」「第 22 章会回来」「这条线留到后面」。

**判据**：删掉之后事实关系还成立吗？成立就不要补回来。需要指路时优先用**内容**认路（「维纳那一代人做的控制论」），不用**编号**认路（「第 7 章那一代人」）。章号只留在读者真会翻回去查的地方。

### 5. 打散句法套路

- 「不是 A，而是 B」——**同一章最多留两三处**，其余改成直接陈述。
- 「真正的问题/原因/意义是……」「这件事的意义比它看起来大得多」——大幅削减。
- 长解释后接平静短句制造反高潮、每节末尾用可摘录的判断封口——**不要每节都来**。
- **破折号减半。** 补充关系不必都写成戏剧性转折；该用逗号、冒号、分号或干脆断句的地方就用。
- **十字以内的独立短段**只留给真正的转场或结论，其余并回上一段。

### 6. 作者判断：留住，但压短

书里那些「这是本书自己的整理，不是哪篇论文的结论」「都是本书自己的对照，不是当年谁的说法」——**这是这本书最值钱的东西之一，审读意见专门表扬了它，一句都不许为了流畅删掉。**

但**形式压到最短**。体例已经在[凡例](../凡例.md)里一次说清了，正文里只留短标记：

- `（本书的对照。）`——跨时代类比
- `（本书的分层。）`——作者的整理和分类
- `（本书的推断。）`——从可查事实往前推了一步

### 9. 清掉欠账区里的流水线语言 ⚠️

**这是这一轮最要紧的一条，因为它已经泄漏到交付物里了。**

章末 `<!-- 欠账: -->` 区块里堆着大量多轮代理协作的工作日志。全书统计：**「本轮」154 处、「第四轮」41 处、「agent」28 处、「下一位」16 处**，还有「主编事项」「本次未动别人的文件」「下一位不必再走网络检索」「403」「OCR 层」这类东西。

而 `tools/build_html.py` 会把每章的欠账区渲染进 HTML（`<details class="debt">`）。外部审读者正是从这里读到了这些日志，并把它列为「AI 深度参与」的**最强证据**——他的原话是「更像多轮代理协作、任务交接和主控汇总留下的工作日志」。**如果这份 HTML 发给出版社编辑，这些东西会跟着一起过去。**

处理办法：

- ✅ **保留核查结论。** 尤其是**负面结果**——「这条路走过，没有结果」是有价值的，能让后来的人不必重走。
- ❌ **删掉工序叙述。** 谁在第几轮做的、用什么工具、哪个端点返回 403、下一位该干什么——全删。
- 改写口径：从**给下一个执行者的交接**，改成**给编辑和作者自己的备忘**。

对照改写：

> **改前**：`- [x] 本轮第四轮联网核实：Al-Jazari 船只循环次数。检索端点 403，OCR 层不可用，下一位不必再走网络检索这条路。`
>
> **改后**：`- [ ] Al-Jazari 自动船的循环次数尚无可靠来源。网络检索已穷尽（含数字化馆藏），需调阅纸本《精巧机械装置的知识之书》。`

注意后一种写法里，**信息一点没少**（结论、已走过的路、下一步该怎么办），少掉的只是工序。

## 四、明确**不要**做的事

审读意见里有几条建议超出这一轮范围，**不要执行**：

- ❌ **不要按 20–25% 砍字数。** 它建议压到 23–26 万字。作者此前明确说过「不需要管超上限的问题」。这一轮删的是工序痕迹，删完自然会缩几个百分点，**那是结果不是指标**。不要为了达标去砍材料。

- ❌ **不要动「订正」区块的事实内容。** 措辞可以顺，结论一个字不改。
- ❌ **不要碰事实。** 见下。

## 五、护栏：事实层零变动

**这一轮改的是「怎么说」，不是「说什么」。**

动手前，为你负责的章存指纹：

```
python3 tools/fact_guard.py snap 第五时代-涌现/29-*.md
```

改完后比对：

```
python3 tools/fact_guard.py diff 第五时代-涌现/29-*.md
```

它盯住五类东西：**年份、数字、引文、「订正」区块标题、外文原名**。

**理想结果是「事实层零变动」。** 如果有变动，每一条都必须是你有意为之、并且能在报告里说出理由的——比如「删掉了一处一次性人物，连带删掉他的生卒年」。**不允许出现"看起来没问题"这种交代。**

改完还要跑：

```
python3 tools/measure.py            # 回填 frontmatter 的 words
python3 tools/ai_tics.py 29 30      # 看痕迹指标降到哪里
```

## 六、交回什么

改完在**你自己那一章的欠账区**记录，不要动别人的文件，也不要动 [人物谱](人物谱.md)、[时间线](时间线.md)、[全书提纲](全书提纲.md)、README——那些由主控统一回填。

报告里写清楚：

1. 每章改前 / 改后的痕迹指标（自指、母题、破折号、不是而是、节数）；
2. 结构上动了什么（有没有改节数、改开头运镜、改结尾）；
3. `fact_guard diff` 的结果，以及每一处变动的理由；
4. **你判断不该改的地方，和理由**——这一条很重要。指标是定位器，不是目标。上一轮粗体审计的教训：某章「我们」出现 22 次，其中 20 次是图灵论证的主语，砍掉就把论证砍坏了。**看见数字高，先去看上下文，再决定动不动。**
