# Markup v1.3.0 — 快速查找和整理已打开的标签页

## 在大量标签页中快速定位文档

标签栏右侧新增固定的「N 个标签页」入口。也可通过 `⌘⇧L`（Windows / Linux 为 `Ctrl+Shift+L`）或命令面板打开「已打开标签页」。

- 按文件名或完整路径模糊搜索全部已打开文档，支持中文，并显示路径以区分同名文件。
- 使用上下键选择、Enter 切换、Esc 退出；切换后自动滚动到当前标签页。
- 搜索不受 Vault 范围或 50 条结果限制；标签栏隐藏时仍可使用快捷键。

## 一次整理所有标签页

- **只保留当前**：保留正在阅读或编辑的文档，关闭其他标签页。
- **关闭全部**：关闭所有文档标签页并返回欢迎页。
- 批量操作始终作用于全部标签页，不受搜索条件影响。
- 固定标签页默认保留；勾选「同时关闭固定标签页」后，可真正只留下当前文档或全部关闭。

## 保护未保存内容与源文件

- 修复桌面版把异步关闭确认当作已同意的问题。现在等待用户确认，取消或弹窗失败时保留文档、搜索条件和输入焦点。
- 关闭前检查有内容的未保存草稿，以及未保存、保存中或保存失败的文件。确认期间新打开的文件不会被加入关闭批次，内容或固定状态变化时会取消关闭。
- 修复阅读模式下编辑器格式规范化可能触发自动保存的问题。浏览和切换文档不再改写源文件；主动编辑仍可正常保存。

## 验证

- 1,091 项单元测试、39 项浏览器回归，以及 macOS 本机验收通过。
- 实际验证 73 个 Markdown 标签页下的路径/中文搜索、切换、只保留当前、关闭全部及原生确认取消。
- 实际打开长文档检查只读行为，并以文件哈希确认原文内容保持一致。
