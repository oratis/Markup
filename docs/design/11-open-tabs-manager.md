# 设计 11 · 查找和整理已打开的标签页

- 日期：2026-11-16
- 状态：已实现
- 背景：用户实际打开了数十个 Markdown 标签页，难以在横向标签栏中定位文件，也难以发现右键菜单中的批量关闭命令。这满足了[设计 10](./10-close-many-tabs.md)中引入可搜索标签页清单的条件。

## 入口与布局

标签栏右侧固定显示「N 个标签页」，横向滚动时仍可点击。单文档时保留入口；仅剩 Welcome 时隐藏标签栏。快捷键 `⌘⇧L`（Windows / Linux 为 `Ctrl+Shift+L`）和命令面板中的「已打开标签页」也能打开面板，包括标签栏被设置隐藏的情况。快捷键可在设置里修改。

面板采用上下布局：标题和总数、搜索框、可滚动的文档列表、当前文档名称与批量操作。沿用应用的浅色、深色、棕褐色主题；在最小 640px 窗口内仍可使用。

## 定位文档

- 搜索范围是所有已打开标签页，包含文件夹之外的文件、草稿、HTML 和 Canvas，不受快速打开的 Vault 范围或 50 条结果限制。
- 文件名和完整路径均可模糊匹配；列表显示路径以区分同名文件，并标明当前、固定、未保存状态。
- 输入框自动聚焦，↑↓ 选择，Enter 切换，Esc 退出；兼容中文输入法组合输入。
- 选中后直接激活现有标签页，保留内存中的未保存内容，并将标签栏滚动到该文件。
- 面板内约束键盘焦点，退出后恢复入口焦点。

## 批量操作

- **只保留当前**：保留实际正在编辑或阅读的文档，关闭其他标签页。搜索高亮不改变“当前”的含义。
- **关闭全部**：关闭全部标签页，回到 Welcome。
- 搜索只用于定位；批量操作始终基于完整标签页列表。面板底部明确说明操作范围。
- 固定标签页默认保留，此时按钮如实显示「保留当前及固定标签页」「关闭未固定标签页」。勾选「同时关闭固定标签页」后，可以真正只留下一个或全部关闭；既有右键菜单和快捷键仍保留固定页保护。
- 关闭前对整个批次只确认一次；取消不关闭任何文件，也保留查询。检查包含未保存修改、保存中、保存失败、有内容的未落盘草稿，以及被修改过的 Welcome；空草稿和未修改的 Welcome 不打扰用户。
- 桌面版使用 Tauri 的异步确认 API，必须等用户确认后才更新标签页。等待期间新打开的文档不加入待关闭批次，内容或固定状态发生变化时取消本次关闭；弹窗调用失败也保留所有文档。
- 沿用已关闭文件恢复栈；磁盘文件不会被删除。草稿没有磁盘副本，关闭确认明确提示内容会丢失。

## 验证

组件与 store 测试覆盖路径消歧、超过 50 个标签页、中文搜索、IME、键盘及焦点、动态打开/关闭、搜索后的批量关闭、固定页显式选择、取消关闭及草稿保护。

浏览器回归使用真实 React/store/编辑器，仅替换 Tauri 文件系统桥接：验证 73 个标签页时的搜索与自动滚动、固定页与批量关闭、未保存内容保护、隐藏标签栏后的快捷键入口，以及深色窄窗口布局。

2026-11-16 至 17 日，arm64 本机安装包通过 Finder 打开 73 个真实 Markdown 文件后验收：README 同名搜索、路径消歧、中文搜索和 Enter 切换正文正确；带筛选时只保留当前得到 1 个正确文档，关闭全部回到 Welcome。原生取消确认保留草稿、查询及输入焦点，确认关闭后面板退出（包含旧 Welcome 被新 Welcome 替换的情况）。

本机文件校验还发现阅读模式会接收 Milkdown 的格式规范化回调并触发自动保存；已在编辑器与应用更新入口阻止这类只读写入。新增真实编辑器回归证明修复前发生意外写入，修复后阅读/切换保持源文件格式，主动源码编辑仍可正常保存。

最终安装包已再次完成 73 标签页操作及两份真实长文档的只读验收。原有 62 个标签页、顺序、当前文档及阅读模式已恢复；两份受到格式规范化影响的文档已按验收前 SHA-256 精确恢复，最终 62 份原文档与 73 份测试文档的哈希均匹配。1,091 项单元测试、39 项 Playwright 测试及 lint 全部通过。
